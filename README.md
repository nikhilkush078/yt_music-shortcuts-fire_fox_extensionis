# YouTube Music Keyboard Controller

A simple Firefox extension to control **YouTube Music** using keyboard shortcuts.

## Features

- ⏭️ Next Song
- ▶️ Play / Pause
- 🔊 Volume Up
- 🔉 Volume Down

## Shortcuts

| Action | Shortcut |
|---|---|
| Next Song | `Ctrl + Alt + Y` |
| Play / Pause | `Ctrl + Alt + I` |
| Volume Up | `Ctrl + Alt + O` |
| Volume Down | `Ctrl + Alt + P` |

Shortcuts can be changed from Firefox's **Manage Extension Shortcuts** settings. :contentReference[oaicite:0]{index=0}
